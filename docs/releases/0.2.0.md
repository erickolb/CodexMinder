# CodexMinder 0.2.0

First packaged release of the independent Windows taskbar companion for Codex usage.

- Square, transparent widget with five-hour and weekly remaining allowances.
- Separate warning colors for each allowance: yellow below 50%, orange below 33%, red below 10%.
- System light/dark themed context menu with local reset times.
- Automatic taskbar placement and optional manual positioning.
- Last known values remain visible during refresh errors.
- Per-user installer, portable ZIP, checksums, startup selection, and uninstall support.

Requires Windows x64 and an existing Codex ChatGPT-subscription sign-in. The installer and app are currently unsigned. No automatic updater is included. See [installation instructions](https://github.com/erickolb/CodexMinder/blob/main/docs/INSTALL.md).
