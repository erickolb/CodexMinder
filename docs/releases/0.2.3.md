# CodexMinder 0.2.3

- Hide the overlay while a foreground fullscreen app or game covers the widget's monitor, including borderless fullscreen.
- Restore the overlay without taking focus when fullscreen ends or the user switches away.
- Keep the tray icon and background usage refreshes active; fullscreen apps on another monitor do not suppress the widget.
- Avoid treating the desktop, taskbar, or conventional maximized windows as fullscreen games.

Requires Windows x64 and an existing Codex ChatGPT-subscription sign-in. Binaries are unsigned. See [installation and upgrade instructions](https://github.com/erickolb/CodexMinder/blob/main/docs/INSTALL.md).
